# 等保 2.0 合规指引（Shadow Agent）

依据 GB/T 22239-2019《信息安全技术 网络安全等级保护基本要求》编制。本文面向
自托管部署 Shadow Agent 的运营单位，映射产品内置能力与差距项，供等级保护
定级备案与测评整改参考。**测评责任在运营单位**，本文不构成法律意见。

## 1. 定级建议

| 部署形态 | 建议级别 | 依据 |
| --- | --- | --- |
| 内部研发/演示环境 | 一级（自主保护） | 受侵害客体仅为自身，无公民个人信息 |
| 企业生产环境（含员工/客户数据） | 二级（指导保护） | 公民个人信息受到侵害 |
| 关键行业或大规模个人信息处理 | 三级（监督保护） | 公民法人合法权益严重损害，需强制测评 |

## 2. 安全技术要求对照（以二级为基准）

### 8.1.4.1 身份鉴别

| 要求 | 产品实现 | 状态 |
| --- | --- | --- |
| 身份标识唯一 | `console_users.email` 唯一约束；managed API key 独立签发 | 内置 |
| 口令复杂度与加密存储 | PBKDF2-SHA256、12 万轮迭代、随机盐；口令长度由 Pydantic 校验（≥6，可按需调高） | 内置 |
| 登录失败处理 | 连续失败锁定（`SHADOW_AGENT_LOGIN_MAX_FAILURES` / `LOGIN_LOCKOUT_SECONDS`），锁定期间返回 429 | 内置 |
| 远程管理防窃听 | 部署方责任：控制台与网关之间启用 HTTPS（反代终止 TLS） | 差距 |
| 双因素鉴别（三级要求） | 差距项：可通过在反代层叠加 TOTP/证书认证实现 | 差距 |

### 8.1.4.2 访问控制

| 要求 | 产品实现 | 状态 |
| --- | --- | --- |
| 角色划分与授权 | admin / security_admin / client / gateway 四角色 RBAC；首个管理员经 bootstrap token 门控 | 内置 |
| 最小权限 | 管理端点强制 `require_admin`，网关端点强制 `require_client` | 内置 |
| 授权主体唯一 | managed API key 逐密钥签发、可撤销、可轮换、可设过期 | 内置 |
| 安全标记（三级要求） | 不适用/差距 | — |

### 8.1.4.3 安全审计

| 要求 | 产品实现 | 状态 |
| --- | --- | --- |
| 审计覆盖 | 拦截日志、认证事件、管理操作（密钥/策略/审批）全量落库 | 内置 |
| 审计内容 | 五要素：时间、主体（principal/email/来源 IP）、事件、结果、request_id | 内置 |
| 审计保护 | 应用层不可篡改接口；**集中日志与防删改需外部措施（见差距）** | 部分 |
| 审计时间同步 | 部署方责任：主机 NTP 同步（时间戳由数据库生成） | 差距 |

### 8.1.4.4 / 8.1.4.5 入侵防范与恶意代码

| 要求 | 产品实现 | 状态 |
| --- | --- | --- |
| 攻击行为发现 | 提示注入检测（直接/间接/多轮）、工具权限、行为风险多层引擎；阻断即告警 | 内置 |
| 边界防护 | 每客户端滑动窗口限流；敏感参数尺寸校验；regex 写入时编译校验 | 内置 |
| 最小安装 | 容器镜像仅含运行时依赖，非 root 用户运行 | 内置 |

### 8.1.4.6~8.1.4.10 数据完整性与保密性

| 要求 | 产品实现 | 状态 |
| --- | --- | --- |
| 传输完整性/保密性 | 部署方责任（TLS）；上游转发携带 Authorization 头不落日志 | 部分 |
| 存储保密性 | 凭证/密钥仅存哈希；日志脱敏（`redact_text` / `sanitize_json`） | 内置 |
| 数据备份恢复 | SQLite + WAL；部署方责任：卷快照/异地备份策略 | 部分 |

## 3. 安全管理要求（运营单位责任清单）

- **制度**：制定安全策略、账号与密钥管理制度（密钥轮换周期建议 ≤90 天）。
- **人员**：指定安全管理员（security_admin 角色对应），审批流至少两人。
- **建设/运维**：变更经审批（产品内置审批工作流可用于工具操作审计）；
  制定应急预案（Redis 故障时限流退化为单实例——见运维手册 fail-open 行为）。

## 5. 与 GDPR 文档的关系

若同时面向欧盟用户，请结合 [gdpr.md](gdpr.md) 完成数据主体权利响应与跨境
传输评估；两套要求在"传输加密、集中审计、备份恢复"上可复用同一套部署措施。
